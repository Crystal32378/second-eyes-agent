# HERO image — generation spec (for the image-model run, not this repo's code)

Source: HERO visual reference brief (Drawer → Desk). This repo cannot
generate photography; whoever runs the image model uses this spec.

## Generation prompt (no text in image)

Archival editorial still life, warm natural daylight. One single wooden
card-catalog drawer, slightly open (not closed, not fully out), filled with
many orderly-but-not-perfectly-aligned index cards. On the wooden desk in
front: (1) two neutral items side by side (NOT a conflict claim — the
"pair must visibly disagree" check was retired from hero duty two rounds
ago; text-heavy disagreement is what image models mangle, so CONFLICT
lives in UI screenshots, never in the hero); (2) one card flipped to its
blank ruled back, clearly visible ruling; (3) a yellow pencil resting on the
ruled card. Shallow depth, quiet, slightly worn, honest. Clean negative
space in one corner. NO text/letters rendered in image. NO computers,
screens, dashboards, glowing indicators, people, whole libraries, museum
perfection, luxury styling.

## Post overlay (added afterward, never generated in-image)

SECOND EYES / Most things stay filed. Questions come to you.

## Three non-negotiable acceptance checks (CORRECTED)

1. Drawer only slightly open.
2. One card shows its BLANK RULED back with a pencil resting on it
   (deliberately reserved, not forgotten).
3. Nothing in frame asserts a claim about a specific archive file
   (neutral objects; overlay must never say "these are your photos").

The retired "desk pair must disagree" check belongs to UI screenshots
only. Do NOT apply it to hero images.

## Provenance correction (standing rule)

Batch A 60 = first 60 rows of a 132-row observation sample, NOT the
archive. The archive (~7.5k files) contains situational photos, documents,
and brand books — non-lingerie content is expected there. "Does not look
like Batch A" NEVER implies untrustworthy. The asset owner's stated
source IS the qualified source; "unverifiable from pixels" is a limit on
pixel-reading, not a verdict on provenance. Hero v4 desk photos: gifted
situational shots, cropped/aged derivatives (not originals), social-media
public use rights confirmed by owner, outside Batch A (no ASSET_ID).

## Standing trap warning (for UI screenshots, not hero)

Folder-vs-garment colour divergence is NORMAL signal (folder wins per
house convention; pilot02 Pink 8/8, Beige 7/7 observed black garments).
Never stage it as CONFLICT — that is over-raising from the other side.
