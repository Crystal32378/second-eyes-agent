How these results were produced

Each supported brief and image subset was evaluated by the existing Python evidence route, publishing gate and coverage function when this sample was built. This page selects that exact result; it does not run a model or reinterpret the gate in JavaScript.

Observations come from the recorded Gemini image run. They are not verified product facts. Owner-supplied facts and measured dimensions retain their sources.

What happens to my files and choices?

No upload path

This version only loads six already-public, brand-approved derivatives and their public evidence. It never requests originals, credentials or private images. The files remain unchanged.

Your choices stay in this page

The app keeps the selected brief, kept photos and optional note in page memory. It does not send them to a model or server, store them in cookies, localStorage or sessionStorage, or put them in a URL.

Clear, reload or leave

Clear my session removes your choices and note from the active page. Reload starts over. Browser session restoration may retain form state; this app clears controls when the page is restored. A downloaded decision is a separate file under your control and is not deleted by Clear.

The hosting boundary

The static host receives normal page and public-asset requests and may retain access logs under its own policy. This app adds no analytics. Public sample files can remain in browser or host caches; they are not private uploads.

What this does not decide

No legal clearance, identity verification, publishing-safety guarantee, taste score or new image analysis. NEW means an unverified observation; UNKNOWN and relevant CONFLICT need evidence. This recorded set happens to contain six NEW observations; other states are not fabricated for the demo.

An unavailable, changed or unreadable sample image stops this experience before candidates are offered. No failure is silently counted as a reviewed photo.
